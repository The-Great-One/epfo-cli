## [0.1.0] - 2026-10-06

### Added
- Read-only EPFO passbook CLI: balances, month-by-month ledger, employment
  history, profile and KYC
- Automatic captcha reading (ddddocr → tesseract)
- OS keychain password storage
- `unified` command: read claims surface via real browser (CDP)
- `--store` change detection with exit-code contract
- 184 passing tests
